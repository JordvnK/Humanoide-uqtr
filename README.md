## Objectif
Un humanoïde de taille enfant (environ 1,25 m, 21 articulations) au design
original. Je fabrique les composants essentiels (actionneurs, structure) et
j'étudie les composants achetés pour les améliorer.

## Feuille de route
- [ ] Module 1 : actionneur maison (moteur BLDC + réducteur cycloïdal), décembre 2026
- [ ] Module 2 : robot complet en CAO, hiver 2027
- [ ] Module 3 : une jambe réelle de 6 actionneurs + simulation, été 2027
- [ ] Module 4 : bas du corps, puis robot complet sous ROS 2
